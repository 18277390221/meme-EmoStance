# 服务器与树莓派通信

从 `zerotier_chat/` 提取的独立通信核心，使用 Python 3.9+ 标准库，无需安装 Python 第三方依赖。只负责 TCP 连接、认证、文字收发和连接维护。

| 文件 | 功能 |
| --- | --- |
| `server.py` | 服务器端：接收树莓派请求、返回确认消息、主动推送、管理客户端。 |
| `client.py` | 树莓派端：连接服务器、发送文字、接收返回与推送、心跳和自动重连。 |
| `common.py` | 公共 UTF-8 JSON 协议、共享口令加载、帧限制和并发写保护。 |
| `init_config.py` | 生成通信口令文件，不显示口令，也不覆盖已有文件。 |

通信核心不依赖其他项目目录。它不包含语音识别、模型训练或推理、情绪分析、表情选择、播放器和硬件控制，也不包含 Windows/WSL 网络安装或部署脚本。

## 启动

把本目录复制到服务器和树莓派。双方需要网络互通，例如已加入同一个可互通的 ZeroTier 网络。

在服务器的 `communication/` 目录生成一次通信口令：

```bash
python3 init_config.py
```

将生成的 `.env` 安全复制到树莓派的同名目录，双方使用同一份口令，不要分别生成。`.env` 已通过本目录 `.gitignore` 排除，不能上传 Git。也可通过环境变量 `ZT_CHAT_TOKEN` 提供口令，环境变量优先。

在服务器终端启动，`SERVER_IP` 换成服务器本机的 ZeroTier 地址：

```bash
SERVER_IP='填写服务器的ZeroTier地址'
python3 server.py --host "$SERVER_IP" --port 9000
```

在树莓派终端启动，填写同一个服务器地址：

```bash
SERVER_IP='填写服务器的ZeroTier地址'
python3 client.py --host "$SERVER_IP" --port 9000 --name raspberrypi
```

在单机验证时，两端均使用 `127.0.0.1`。服务端默认监听 `127.0.0.1:9000`；客户端必须显式提供 `--host`，没有写死的机器地址。

连接成功后：

- 树莓派输入文字并回车，服务器接收后返回 `服务器已收到：原文字`，用于验证通信。
- 服务器输入文字并回车，主动推送给所有已认证客户端。
- 服务器输入 `/clients` 查看在线设备。
- 两端均可用 `/help` 查看命令、`/quit` 或 `Ctrl+C` 退出。

回显只用于通信确认。业务层如果需要返回其他文字，应在此目录外实现；可通过 Python 调用 `ChatServer(token, on_text=callback)`，同步回调接受 `(text, client_name)` 并返回字符串。通信层不导入模型模块，回调实现保留在业务层。

## 协议与行为

TCP 长连接采用一行一帧的 UTF-8 JSON，兼容原 `zerotier_chat` 消息格式：

| 类型 | 方向 | 用途 |
| --- | --- | --- |
| `hello` / `hello_ok` | 客户端 → 服务器 / 服务器 → 客户端 | 共享口令认证和连接确认。 |
| `request` / `result` | 客户端 → 服务器 / 服务器 → 客户端 | 通过 `id` 对应请求和返回，正文为 `text` 字符串。 |
| `push` | 服务器 → 客户端 | 主动推送文字。 |
| `ping` / `pong` | 双向 | 心跳保活。 |
| `error` | 服务器 → 客户端 | 认证、协议、队列或回调错误。 |

示例请求与返回：

```json
{"type":"request","id":"request-001","text":"你好"}
{"type":"result","id":"request-001","text":"服务器已收到：你好"}
```

请求结果只发回提出请求的连接；主动推送发给所有已认证连接。正文支持中文、换行和 emoji，整帧上限为 1 MiB。客户端每 15 秒发送心跳，读超时为 60 秒；断线后按最多 15 秒的间隔重连。断线期间不排队新消息，已发送但未确认的请求不会自动重发，避免重复处理。

`result.text` 始终为字符串；业务层可自行编码 JSON 字符串，通信层不解释业务字段。共享口令用于认证，TCP 本身未增加 TLS；跨设备使用时由既有 ZeroTier 网络提供链路加密。
