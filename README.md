# meme-EmoStance

本项目用于管理数据集、通过 EmoStance 训练好的模型、meme 猫素材，以及在树莓派上运行的播放软件。

| 文件夹 | 功能 |
| --- | --- |
| `dataset/` | 存放数据集。 |
| `data_spilt/` | 存放划分好的数据集，例如训练集、验证集和测试集。 |
| `meme_software/` | 存放在树莓派上运行的播放软件。 |
| `sucai_meme/` | 存放 meme 猫的素材。 |
| `model/` | 存放通过 EmoStance 训练好的模型。 |

`data_spilt` 沿用项目现有目录名称。当前上述目录通过 `.gitkeep` 占位文件保留结构，实际数据、软件、素材及模型文件后续放入对应目录。
