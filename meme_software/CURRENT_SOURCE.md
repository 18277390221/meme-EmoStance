# 源码快照与验证范围

本次源码来自VSCode Remote SSH的只读“下载”操作：树莓派现用player/desktop及player/launch.py，不是work/native-player旧副本。下载desktop中的既有SHA256SUMS共38项逐字节匹配，所有Python源文件通过Python3.11语法检查。

用户明确授权把当前Pi新增的音乐控制及待机语音一起提交。当前Pi已包含协议2、严格半双工、0.7秒结束静音和有称呼的本地待机/唤醒实现；本次保留这些实际内容。早先聊天内旧包或旧测试不能当作这份新快照的验证证据，也不在此次发布中重新运行旧安装包。

发布仅做可移植性处理：默认服务器localhost占位、移除README机器绝对路径、重建源码清单、补充来源/运行说明和纯逻辑回归检查。不写回Pi，不运行麦克风、不更换模型、不启停播放器或音频服务。

未上传模型、媒体、数据库、虚拟环境、离线依赖、口令、个人speech-config、缓存或用户音频/转写。仓库已有sleep模块和媒体保留原Git blob。树莓派残留的turn_detector历史代码未复制进本次新增源码，不代表重新启用Silero/Smart Turn。

已有VALIDATION记录中的211套素材/旧lite验证属于历史；此次VALIDATION.json仅记录当前发布检查。新Pi麦克风、扬声器路由、触屏、音乐回灌、真实服务器算法、准确率/CER和端到端延时均未在此次源码发布中重验，不把语法/逻辑测试称为实机通过。

发布副本新增10项纯逻辑检查通过：协议2就绪/单请求/end标记、回复校验、音乐/待机指令与状态、选曲标签权重、USB重试撤销/预算及稳定卡名解析。运行：`python3 -m unittest discover -s meme_software/tests -v`。这些测试不占麦克风、不联网、不播放声音。
