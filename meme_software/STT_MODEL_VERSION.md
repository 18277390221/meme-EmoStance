# 当前语音模型：第一版（V1）

“第一版”是本项目当前交付的语音方案版本标记，不是上游模型的版本号，也不表示本项目训练过新模型。

- 引擎：本地 sherpa-onnx，现有离线安装版本1.13.8。
- 配置：原中文轻量 lite；模型为 `sherpa-onnx-streaming-zipformer-small-ctc-zh-int8-2025-04-01`。
- 运行：树莓派CPU，本地16kHz单声道PCM16；仅最终识别文字发送服务器，不保存或上传音频。
- 断句：原ASR静音端点，start.sh设0.5秒。不使用Silero VAD、Smart Turn或新中英方案。
- 模型预加载并常驻；等待服务器回复/新回复待播时暂停本轮收音，播放新回复时开启收音。

播放期间可说话；用户说完后才发送整句。新回复即使提前到达，也必须等旧GIF完整一轮及本地配套WAV实际结束再开始。没有新回复时，旧播放结束不会重置正在说的半句。仍只允许一个待确认请求，重复/过期回复不播放。

本次仅提交程序源码和说明，不上传模型权重、媒体、虚拟环境、离线wheel、口令或本机配置。模型复用已有离线安装；授权和来源见原离线包内MODEL-SOURCES及licenses，不把项目V1标记当作上游许可。

已验证15项主机行为检查、真实Windows Tk＋本机TCP两轮逻辑（模拟麦克风/声音时长），并观察到Pi更新器成功。新模式的真实Pi麦克风/扬声器回灌及实际服务器回复仍待现场验收；未实现声学回声消除。
