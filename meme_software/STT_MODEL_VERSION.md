# 当前STT方案

这是现用树莓派源码快照，不是新训练或新模型版本。历史“V1/第一版”仅为项目早期交付标记。

- 引擎：完全本地sherpa-onnx，现有环境1.13.8。
- 模型：sherpa-onnx-streaming-zipformer-zh-int8-2025-06-30（Transducer）。文件为encoder.int8.onnx、decoder.onnx、joiner.int8.onnx、tokens.txt。
- 当前配置：CPU 2线程，16kHz单声道PCM16；start.sh结束静音0.7秒；不开启Silero VAD或Smart Turn，不改模型参数。
- 模型在ASR进程内常驻，普通聊天与本地音乐/待机控制复用。仅完整最终文字按协议发送服务器；临时文字和音频不上传。
- 早先Pi公开3样本回放RTF为1.628/1.631/1.964，未达到持续实时；这属于当时的软件/负载条件，不是本次新配置性能验收。
- 先前Windows回放和静音/噪声测试不能证明Pi实际准确率、无漏字、端到端延时或回声效果。本次发布不修改现用模型和断句参数，不宣称已解决这些问题。

不上传模型权重、原始音频、用户转写、运行配置或凭据。来源和许可沿用原离线模型包；不凭INT8/CPU字样推断授权或GPU加速。
