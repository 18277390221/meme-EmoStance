# 本地素材库

在这里放入已有播放器的 `assets.sqlite3` 副本。库内包含表情和配套声音，程序沿用原编号、配对和场景绑定。请在停止旧播放器后备份并复制数据库；不要复制正在写入的 SQLite 文件，也不要以空库覆盖原素材。

本次 GitHub 仅提交关键源码，不包含该数据库或媒体。原生入口缺库或空库时会明确停止，不会自动下载媒体或重建 211 套素材。数据库与运行备份已被 `.gitignore` 排除。

现有完整素材库在主机检查时有 211 套，已删除的 5 个编号为 meme-0056、meme-0153、meme-0175、meme-0176、meme-0179。保留实际现有库，后续数量以用户维护后的库为准。
