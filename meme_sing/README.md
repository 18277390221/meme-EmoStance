# Meme 本地音乐

在聊天时说“想听音乐”“放首歌”“来点音乐”，树莓派会从本地音乐目录选一首播放。正在播放时，说“停止”“停止音乐”“别放了”或“不听了”结束音乐并恢复聊天。没有音乐在播放时，“停止”等内容继续交给对话模型处理。

默认素材目录：

```text
/home/aida/meme/meme-EmoStance/sucai_meme/meme_music
```

通过播放器 `--music-dir` 可以指定其他目录。音乐目录缺失或播放器启动失败只影响点歌功能，普通聊天可以继续。使用系统已有的 `ffplay` 播放，默认音量为 30%，音乐播放期间与表情配套声音互斥。

选曲优先采用用户本次明确指定的风格，例如“放首开心的音乐”。没有指定时，使用最近成功问答的文字，通过本地情绪词规则匹配文件名标签。`浪漫5，愉悦5` 这样的数字作为标签权重；文件名末尾的编号不是唯一歌曲 ID。每个新的服务器 `conversation_id` 都清空上一段情绪记录，失败请求和点歌不进入聊天记录，也不推进四轮滚动上下文窗口。没有足够情绪线索时选轻松、愉悦的音乐。

音乐模式保留本地停止指令识别；其临时识别结果和歌曲歌词不会发送给服务器。普通聊天仍在完整断句后提交，沿用 0.7 秒断句等待。音乐自然结束、停止或播放失败后，恢复普通聊天；关闭语音、断线或退出播放器时结束本应用启动的音乐进程。

USB 录音设备掉线时立即停歌并暂停收音，界面提示等待设备恢复。设备重新出现后只重启本地识别进程，不重载服务器模型，也不自动续播音乐。设备长期缺失时持续等待，不消耗重试次数；设备存在但恢复启动失败时，最多尝试 5 次，间隔为 1、2、4、8、8 秒。非设备故障保留错误提示，不自动反复重启。手动暂停收音、关闭语音或退出应用会取消恢复；沿用 0.7 秒断句和服务器四轮滚动窗口规则。

USB 音箱重连后，播放器按稳定的 USB sink 名称恢复默认输出，解除意外静音并保留已有非零音量。音乐和表情配套声音都使用这个 USB 音箱，不因设备编号改变而转到板载输出。USB 仍缺失时等待；硬件已出现但系统音频尚未枚举音箱时，每次掉线恢复最多尝试重启一次当前用户的 WirePlumber，不反复重载音频服务，也不重载服务器模型。恢复检查需分别确认音乐和表情声音的实际 sink 路由，仅识别进程恢复不算声音恢复。

音乐播放使用较低音量和稳定停止短语检测，现场仍需根据扬声器与麦克风位置调整音量。本实现没有新增声学回声消除模块。

代码位于本仓库 `meme_sing/`，部署时复制到树莓派播放器的 `player/desktop/meme_sing/`。`model_information`、`model_information_qwen` 和 `model_information_qwen_3.0` 使用同一套本地功能，无需修改模型参数。
